### 👨‍💻 About Me

I am a passionate **Full-Stack Software Engineer** dedicated to building maintainable, resilient, and high-performance software. I combine strict **Object-Oriented Programming (OOP) and SOLID architectural principles** on the backend with responsive, modern, user-first frontends.

- 🔭 **Currently Building:** [FoodEase](https://github.com/tomkarrao-commits/veg-nonveg-eats) — An enterprise-grade South Indian food ordering platform powered by Java 21, Spring Boot 3, and React 19.
- 🌾 **Impact Engineering:** [OpenQuest](https://github.com/tomkarrao-commits/OpenQuest) — A deterministic agricultural rule engine for government scheme eligibility, Mandi price intelligence, and direct cooperative planning.
- 📐 **Engineering Philosophy:** Strong typing, clean domain models, zero-hallucination deterministic business logic, and modular component design.
- 💬 **Ask Me About:** Java & Spring Boot ecosystem, React & modern frontend state management, REST API architecture, database modeling, and OOP design patterns.
