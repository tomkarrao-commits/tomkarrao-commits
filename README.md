### 👨‍💻 About Me

I am a passionate **Full-Stack Software Engineer** dedicated to building maintainable, resilient, and high-performance software. I combine strict **Object-Oriented Programming (OOP) and SOLID architectural principles** on the backend with responsive, modern frontends and intelligent machine-learning pipelines.

- 🔭 **Enterprise Full-Stack:** [FoodEase](https://github.com/tomkarrao-commits/veg-nonveg-eats) — Full-stack South Indian food ordering platform powered by Java 21, Spring Boot 3, and React 19.
- 🛕 **AI & Computer Vision:** [YatraSetu](https://github.com/tomkarrao-commits/Yatrasetu) — Real-time crowd analytics and ML anomaly prediction ecosystem integrating Ultralytics YOLO, FastAPI, and React.
- 🌾 **Impact Engineering:** [OpenQuest](https://github.com/tomkarrao-commits/OpenQuest) — Deterministic agricultural rule engine for government scheme eligibility, Mandi price intelligence, and direct cooperative planning.
- 📐 **Engineering Philosophy:** Strong typing, clean domain models, zero-hallucination business logic, and modular, testable components.
- 💬 **Ask Me About:** Java & Spring Boot ecosystem, React & Vite, Python, FastAPI, YOLO Computer Vision, REST APIs, and OOP Design Patterns.
